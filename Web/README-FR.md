# Hero’sPath - modules web

Ces modules documentent et testent les transformations utilisées par le renderer de démonstration. Ils ne sont pas chargés par l’addon en jeu.

- `replay-renderer.js` - replay, interpolation et rendu du trajet ;
- `map-native-adapter.js` - projection et adaptation des sources cartographiques ;
- `outdoor-map-projection.js` - conversion coordonnées monde → coordonnées de carte.

Le point d’entrée utilisateur de la démonstration reste `Demo/index.html`.
