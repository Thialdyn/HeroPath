# HeroPath - Démo

Ouvrez `index.html` pour explorer le parcours, les événements, les transports et les différents fonds de carte.

Le bouton ⚙ permet d’ajuster la taille des icônes, l’épaisseur du trajet, le contour, la légende et l’affichage des points enregistrés.

Sous Windows, vous pouvez aussi lancer `../launch-demo.bat`. Avec Python : `python ../launch-demo.py`.
