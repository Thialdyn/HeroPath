# Limites connues

1. Un crash brutal du client avant l’écriture des SavedVariables peut perdre le tail encore uniquement en mémoire.
2. Aucun test hors-client ne peut garantir tous les comportements spécifiques d’un fork WoW ; une validation sur Forever reste nécessaire.
3. Bateau et zeppelin ne sont pas identifiés par simple proximité de terminaux : Hero’sPath préfère une cause inconnue à une attribution non prouvée.
4. Les intérieurs d’instance/BG ne produisent pas de polyline extérieure ; seuls les événements d’entrée/sortie et la durée sont conservés.
5. Le renderer fourni est une démonstration locale et non un service web hébergé.
